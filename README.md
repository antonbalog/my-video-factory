# my-video-factory

A dynamic JSON-driven video factory built on [Remotion](https://www.remotion.dev). Scenes are defined in `public/script.txt`, audio is generated by `generate-audio.ps1`, and the result is rendered as a React video.

## Prerequisites

All of the following must be installed and available in `PATH` before running the audio pipeline.

### Windows

| Software | Version | Purpose | Install |
|---|---|---|---|
| **Node.js** | 18+ | Remotion / npm | [nodejs.org](https://nodejs.org) |
| **Python** | 3.11+ | edge-tts | [python.org](https://python.org) |
| **edge-tts** | any | Text-to-speech | `pip install edge-tts` |
| **ffmpeg** | any | mp3 → wav conversion | [ffmpeg.org](https://ffmpeg.org) |
| **rhubarb** | 1.13+ | Lip sync (wav → mouth.json) | [github.com/DanielSWolf/rhubarb-lip-sync](https://github.com/DanielSWolf/rhubarb-lip-sync) |
| **WSL2** (Ubuntu) | any | Hosts Resemble Enhance | `wsl --install` (then restart) |

### Inside WSL (Ubuntu)

After WSL is installed, run these once in the Ubuntu terminal:

```bash
# 1. System packages
sudo apt-get update
sudo apt-get install -y git-lfs python3.11 python3.11-venv python3.11-dev
git lfs install

# 2. Python venv with Resemble Enhance
python3.11 -m venv ~/enhance-env
~/enhance-env/bin/pip install --upgrade pip
~/enhance-env/bin/pip install torch==2.1.1 torchaudio==2.1.1 resemble-enhance

# 3. Enhancement script
cat > ~/enhance.py << 'EOF'
import sys
import torch
import torchaudio
from resemble_enhance.enhancer.inference import enhance

input_path = sys.argv[1]
output_path = sys.argv[2]

dwav, sr = torchaudio.load(input_path)
dwav = dwav.mean(0)

device = 'cuda' if torch.cuda.is_available() else 'cpu'
enhanced, sr_out = enhance(dwav, sr, device, nfe=64, solver='midpoint', lambd=0.1, tau=0.5)

torchaudio.save(output_path, enhanced.unsqueeze(0), sr_out)
EOF
```

> The first run of `generate-audio.ps1` will download the Resemble Enhance model weights (~300 MB via git-lfs automatically).

## Commands

```bash
npm i                          # Install Node dependencies
npm run dev                    # Start Remotion Studio (live preview)
npm run lint                   # ESLint + TypeScript type-check
npx remotion render            # Render the video
```

```powershell
# Generate all audio (TTS + enhancement + lip sync)
powershell -ExecutionPolicy Bypass -File .\generate-audio.ps1

# Render to out/youtube.mp4 and out/shorts.mp4
powershell -ExecutionPolicy Bypass -File .\render.ps1

# Render a single composition
powershell -ExecutionPolicy Bypass -File .\render.ps1 -Composition Youtube
powershell -ExecutionPolicy Bypass -File .\render.ps1 -Composition Shorts
```

## How it works

1. Edit `public/script.txt` to define scenes and dialogue
2. Run `generate-audio.ps1` — generates mp3, vtt, and mouth.json for each line
   - Uses hash-based caching — unchanged clips are skipped automatically
   - Audio pipeline: `edge-tts → ffmpeg → Resemble Enhance → loudnorm → rhubarb`
3. Open Remotion Studio (`npm run dev`) to preview
4. Render with `npx remotion render`

## script.txt syntax

```
[Scene]                             scene header (auto-numbered)
[Scene transition=zoom-in]          with optional transition
[Scene N]                           explicit scene number (also auto-advances counter)
[Intro duration=120]                fixed-duration intro (frames)
[Outro duration=120]                fixed-duration outro (frames)

SHOW character [flags]              place character on screen
ANIMATE character type at=Xs        play animation at timestamp
SFX path/to/file.wav at=Xs         play sound effect at timestamp
CHARACTER: dialogue text            one line of TTS dialogue
{bleep:word}                        censored word (plays beep + censors subtitle)
```

**SHOW flags:** `x=0.5` `y=0.5` `size=2` `nametag` `wave` `wave=outro` `trim-start=0.5s` `trim-end=0.2s` `pad-end=0.5s`

**ANIMATE extras:** `cycles=3` `return=30`

Example:

```
[Scene]
ANIMATE bryan glitch-in at=0s
SHOW dirtbag nametag
DIRTBAG: Hello! This is my very first video
SHOW bryan nametag

[Scene transition=zoom-in]
SHOW bryan
BRYAN: And hopefully also the last
```
